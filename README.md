# Blog Platform with Comments

## Overview
A blogging interface to create posts and add comments.

## Features
- Create blog posts
- Add comments to posts
- Delete posts from the page
- Posts saved in browser localStorage
- Express API starter for posts and comments

## Technology stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js and Express
- Persistence: browser localStorage for the interactive demo; JSON files for the sample API
- Responsive layout for desktop and mobile

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000
